<h1 align="Left">Hi there 👋, I'm Rakesh Vadnala</h1>

<p align="Left">I'm an Identity and Access Management (IAM) professional specializing in designing, developing, and implementing end-to-end identity governance solutions using <strong>SailPoint IdentityIQ</strong> and <strong>Saviynt IGA</strong>.</p>

<p align="Left">My core IAM expertise includes user and role management, access reviews, RBAC, policy enforcement, provisioning/deprovisioning, and full identity lifecycle management across Joiner, Mover, and Leaver (JML) processes. I have extensive experience in application onboarding across Active Directory, JDBC, LDAP, web services, Linux Direct, Cloud Gateway, MSSQL, and SCIM 2.0 — along with deep knowledge of SailPoint modules including Compliance Manager, Lifecycle Manager, and Password Management.</p>

<p align="Left">I have good knowledge of <strong>CyberArk PAS</strong>, spanning Enterprise Vault, Privileged Session Manager, and Central Policy Manager.</p>

<p align="Left">My infrastructure background spans Linux and Windows environments, including Windows Server 2016 (AD DS, Group Policy, DNS, IIS, DFS, WDS, Hyper-V, DHCP) and CentOS 7 administration. Beyond IAM, I have a keen interest in <strong>Arduino and IoT</strong>, with practical experience in embedded systems development.</p>
